Progetto:

    Todo list

Sviluppatore:

    Zhu Donglai

Descrizione:

    Todo List Flutter è un’applicazione per gestire i Todo in stile Google Keep.
    Permette di aggiungere, modificare, completare e cancellare la lista in modo.
    Ogni Todo appare in una Card verticale con checkbox, testo e un cestino per rimuovere.
    È possibile aggiungere nuovi Todo tramite il pulsante + in basso.

Scelte di sviluppo:

    Flutter – linguaggio richiesto.
    Card verticali – rendere la UI scorrevole.
    Checkbox, testo e delete – rendere il todo personalizzabile.
